# Logic-Gates
A physical magnetically connecting set of logic gates, inputs and outputs to simulate logic gates in real life!

A set of magnetically connecting tiles, each with their own functions that work together to form electrical circuits, which can be used to teach logic gates in classrooms or simulate circuits without the need of a breadboard.
